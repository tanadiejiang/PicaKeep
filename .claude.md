# Claude compatibility instructions

The canonical project instructions are in [CLAUDE.md](CLAUDE.md) and
[AGENTS.md](AGENTS.md). Apply both files when working in this repository.

The following project rule is mandatory: application builds may use only
`debug` or `profile`. Release builds are forbidden. Do not run or recommend
`flutter build ... --release`, and do not use an install command that can
uninstall the existing app or erase its data. Verify the APK path and device
before installation.
