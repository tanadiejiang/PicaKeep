# AI 工具插件

入口：设置 → AI → AI 工具插件。搜图默认使用内置新版适配，无须自行导入。

## 导入与恢复

选择 UTF-8 JSON 文件，检查预览中的工具名称、版本与目标域名，再点导入。启停、导出清单、公开诊断、恢复上一版均在插件卡片；内置搜图还有“恢复内置”。导出通过复制完整 JSON，保存为 `.json` 后可在另一安装导入。规则保存在应用内部 `ai_tool_plugins/plugins.json`，不随下载目录移动。

更新在下一次工具调用生效，无须重新打包 APK。失败导入保留现版本；成功更新保存上一版。修改插件名称不改变工具 ID。每个插件独立开关，搜图还需开启原有“以图搜源”能力。

## 让对话 AI 维护

在管理页打开“允许 AI 维护插件”（默认关闭），再在对话要求检查某个插件。AI 可使用 `manage_tool_plugin` 的 list、read、diagnose、update、rollback。诊断仅 GET 已安装来源的公开页面，不上传图片；可传同站点公开 JS 路径查看当前接口。

AI 只能更新已经安装的插件，网络 origin 和执行器类型不能改变；新增来源需要在管理页导入。规则检查通过不等于真实业务验证通过，更新后应正常调用工具确认，必要时恢复上一版。“仅本地”对话会阻止这些网络工具和维护工具。网页内容只作为诊断数据。

## 清单格式

两种执行器共用 `schemaVersion=1`、稳定 `id`、`name`、`version`、`kind`、`endpoint`。

- `image_search`：当前支持搜图 Bot；[内置清单](soutubot.json)包含上传字段、普通表单参数、结果数组/路径数组/分数/ID路径、每个结果字段的候选路径。支持新版嵌套结果，也保留旧 `data` 响应兼容。字段路径是以点分隔的 JSON 键，不是脚本。
- `http_json`：公开 HTTPS GET 查询，[示例](http-json.example.json)需要先换成真实服务地址。`parameters` 定义文本参数名称与说明，`query` 可用 `{参数名}` 插值，自动编码查询串；`resultPath` 为结果字段路径，空串返回整个 JSON。注册后的工具名是 `plugin_<id>`。此类型将结构化数据交给 AI，不自动假设是漫画结果卡。

不支持任意代码、系统命令、认证 header、任意本地文件访问或新的原生执行器。未来遇到全新上传协议、签名算法、登录方式，需要新增执行器代码；单纯 URL 路径、请求字段或 JSON 结构变化可通过清单修正。

## 限制与故障

清单上限64KiB、最多32个插件、插件库4MiB。公开查询不继承应用凭据/cookie，拒绝内网地址与重定向，响应2MiB/工具结果64K字符，DNS10秒、请求总45秒。搜图仍走现有cookie/Cloudflare人工验证链路，图片10MiB、响应8MiB、总90秒，验证成功后最多重试一次并重新检查能力开关。

公开诊断成功仅证明页面可读；搜图可能另外遇到站点限流、权限或人机验证。不要把这类错误统称为签名失效。规则文件损坏会回退内置并提示，首次后续写入会备份旧文件。

本轮验证见 `docs/verification/ai-image-search-57`：合成几何图真实上传 HTTP200，新响应84个路径全部可转换；此验证未使用用户图片，也不覆盖用户设备上的Cloudflare过程。
