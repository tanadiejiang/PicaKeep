# 新增在线源站接入指南

本指南介绍如何用 `BaseOnlineComicPage<T>` 基类快速接入一个新的在线漫画源站详情页。

> 配套文件：
> - `lib/pages/online_comic/base_online_comic_page.dart` — 基类（UI 层）
> - `lib/pages/online_comic/online_comic_page_logic.dart` — 状态逻辑层
> - `lib/pages/online_comic/online_comic_page_components.dart` — 通用组件
> - `lib/pages/online_comic/example_source_page.dart` — 可编译的完整示例

---

## 一、设计理念

- **页面本体无状态**：子类继承 `BaseOnlineComicPage<T>`（`StatelessWidget`），所有可变状态外置到 `OnlineComicPageLogic<T>`，通过项目现有的 `StateBuilder` 绑定刷新。
- **适配器模式**：不强制统一数据模型。子类通过 `extractXxx()` 方法把自己的模型 `T` 适配成基类需要的字段，源站数据模型保持独立。
- **强制 + 可选**：核心方法强制实现，功能性方法带默认值可选重写。返回 `null`/空的可选项对应区块自动隐藏。
- **UI 完全统一**：封面信息区、动作按钮、标签区、章节区、简介区、推荐区全部由基类构建，子类不写任何 UI 代码。

---

## 二、方法清单

### 强制实现

| 方法 | 作用 |
|------|------|
| `Future<Res<T>> loadData()` | 加载详情数据（核心网络入口） |
| `String get tag` | 状态管理唯一标识，建议 `'$sourceKey_$id'` |
| `String get id` | 漫画 ID |
| `String get sourceKey` | 源站标识（如 `'jm'`），用于搜索/图片 |
| `String get source` | 源站显示名称（可 `.tl` 翻译） |
| `String? extractTitle(T)` | 提取标题 |
| `String? extractCover(T)` | 提取封面 URL |
| `Map<String,List<String>>? extractTags(T)` | 提取标签分组（key=分类名） |
| `void onTagTap(BuildContext, tag, category)` | 标签点击/搜索 |
| `void onRead(BuildContext, T, {int ep})` | 阅读（ep 为 1-based） |
| `void onDownload(BuildContext, T)` | 下载 |
| `void onFavorite(BuildContext, T)` | 收藏 |
| `Future<bool> loadFavoriteState(T)` | 加载收藏态 |

### 可选重写（带默认值）

| 方法 | 默认 | 作用 |
|------|------|------|
| `String? extractSubTitle(T)` | null | 副标题（通常作者） |
| `String? extractDescription(T)` | null | 简介 |
| `int? extractPages(T)` | null | 总页数 |
| `int? extractViews(T)` | null | 浏览量 |
| `int? extractLikes(T)` | null | 点赞数 |
| `int? extractComments(T)` | null | 评论数 |
| `List<String>? extractEpisodes(T)` | null | 章节名列表（空=隐藏章节区） |
| `List<OnlineComicRecommendation>? extractRecommendation(T)` | null | 相关推荐（空=隐藏） |
| `get onLike` | null | 喜欢回调（非空才显示按钮） |
| `get onComment` | null | 评论回调（非空才显示按钮） |
| `get onEpisodeLongPress` | null | 章节长按（如 JM 强制在线） |
| `onRecommendationTap(BuildContext, T, index)` | 空 | 推荐项点击 |
| `get imageHeaders` | null | 图片请求头（JM 传 `getJmImgHeaders()`） |
| `get episodesSubtitle` | null | 章节区说明文案 |
| `buildCustomSection(BuildContext, T)` | null | 标签区后插入的自定义区块 |

## 三、数据模型要求

基类不要求模型继承任何接口。你的模型 `T` 只要能提供下列语义字段即可（通过 `extractXxx()` 桥接）：

- **必需**：标题、封面 URL、ID。
- **标签**：`Map<String,List<String>>`，key 是分类名（如「作者」「标签」），value 是该类标签。某类为空就不放进 Map，对应行自动消失。
- **可选**：副标题、简介、页数、浏览量、点赞数、评论数、章节名列表、推荐列表。

> 参考：`PicacgComicItem` 继承自 `BaseComic`，title/cover/id 等可直接读 getter；`JmComicInfo` 不继承任何基类，封面字段叫 `coverUrl`、作者用 `author` getter、章节数 `series.length`，需逐字段桥接。两者都能用本基类接入。

## 四、接入步骤（6 步）

1. **确认数据模型**：已有 `XxxComicInfo` 模型与 `XxxNetwork().getComicInfo(id)` 返回 `Res<XxxComicInfo>`。若无，先实现网络层和模型（不在本基类职责内）。
2. **新建页面类**：`class XxxDetailPage extends BaseOnlineComicPage<XxxComicInfo>`。
3. **实现强制方法**：`tag` / `id` / `sourceKey` / `source` / `loadData` + 四个 `extractXxx` + 四个交互回调 + `loadFavoriteState`。
4. **按需重写可选方法**：有浏览量/点赞/评论/章节/推荐就重写对应 `extractXxx`；需要喜欢/评论按钮就实现 `onLike`/`onComment`；图片要鉴权头就重写 `imageHeaders`。
5. **收藏态同步**：在 `onFavorite` 网络操作成功后调用 `refreshFavorite(newValue)` 刷新收藏图标。
6. **接入路由**：在源站详情入口处 `Navigator.push(AppPageRoute(builder: (_) => XxxDetailPage(id)))`。

## 五、完整示例

见 `lib/pages/online_comic/example_source_page.dart`（用真实 JM 模型演示，可直接编译）。核心骨架：

```dart
class ExampleSourcePage extends BaseOnlineComicPage<JmComicInfo> {
  const ExampleSourcePage(this.comicId, {super.key});
  final String comicId;

  @override
  String get tag => 'example_$comicId';
  @override
  Future<Res<JmComicInfo>> loadData() => JmNetwork().getComicInfo(comicId);
  @override
  String get id => comicId;
  @override
  String get sourceKey => 'jm';
  @override
  String get source => '示例源站';

  @override
  String? extractTitle(JmComicInfo d) => d.title;
  @override
  String? extractCover(JmComicInfo d) => d.coverUrl;
  @override
  Map<String, List<String>>? extractTags(JmComicInfo d) => {
        if (d.authors.isNotEmpty) '作者': d.authors,
        if (d.tags.isNotEmpty) '标签': d.tags,
      };

  @override
  Future<void> onRead(BuildContext context, JmComicInfo d, {int ep = 1}) async {
    await History.ensureForLocalRead(
      target: d.id, type: HistoryType.jmComic,
      title: d.title, subtitle: d.author, cover: d.coverUrl, ep: ep,
    );
    if (!context.mounted) return;
    Navigator.of(context).push(AppPageRoute(
      builder: (_) => ComicReadingPage(JmReadingData(info: d), 1, ep)));
  }

  // onTagTap / onDownload / onFavorite / loadFavoriteState 见示例文件
  @override
  Map<String, String>? get imageHeaders => getJmImgHeaders();
}
```

## 六、常见问题与注意事项

- **交互回调为什么带 `BuildContext`？** 子类是 `StatelessWidget`，导航、弹窗、SnackBar 都需要 context。基类在 build 时把 context 传给每个回调，子类异步操作后务必用 `if (!context.mounted) return;` 守卫。
- **收藏图标不刷新？** 收藏按钮图标由 `logic.favorite` 驱动。`loadFavoriteState` 决定初值，`onFavorite` 成功后必须调 `refreshFavorite(value)` 才会更新。
- **某个区块想隐藏？** 让对应 `extractXxx` 返回 `null` 或空集合即可（标签/简介/章节/推荐区都支持）。
- **图片加载失败/需要鉴权？** 重写 `imageHeaders`。无 `cached_network_image`，封面统一走 `Image.network` + 占位兜底。
- **`tag` 冲突？** 同时打开多个详情页时 `tag` 必须唯一，务必带上 `id`。
- **AppBar 标题不显示？** 这是设计行为——标题随滚动越过封面高度（136px）后才淡入。
- **标签翻译** `enableTagsTranslation` 在 `BaseComic` 中恒为 false 且无执行逻辑，当前直接显示原始标签；如需翻译需另行实现。
- **不要改动现有页面**：`OnlineComicDetailPage`（PicaCG）和 `JmComicDetailPage`（JM）保持原样，本基类仅用于后续新增源站。
