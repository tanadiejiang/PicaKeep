# PK-04：在线详情收藏到本地

日期：2026-09-08。分支：`codex/fix-online-local-favorites`，基于 main，独立于 PK-01/PK-02。

## 问题与修复

当前注册的四个在线源为 Pica、JM、EH/ExHentai、NH。Pica/JM 的实际 V2 详情页“收藏”只调用平台接口；旧 Pica 页的本地收藏实现未被实际入口使用。EH/NH 已有本地入口，但添加和取消都写死 `local` 收藏夹：没有该夹时添加失败，在其他夹内已收藏时取消也无法正确处理。

现在从四个来源的详情页“收藏”均可进入本地收藏操作：

- Pica/JM 先选择“本地收藏夹”或“平台收藏”，只有明确选择平台时才继续原平台操作。
- EH/NH 沿用已有收藏面板，其本地选项打开统一收藏夹对话框。
- 本地对话框列出真实收藏夹及当前漫画的勾选状态，可在指定夹内添加或取消；可新建并收藏，无收藏夹时给出新建入口。关闭对话框不会自行创建默认夹。
- 判断与取消使用“来源类型 + 目标 ID”，避免 JM/NH 数字 ID 相同造成串收藏。取消只影响选中的夹，不影响其他夹或平台收藏。
- EH 保留完整画廊 URL，Pica/JM/NH 保留各源原始 ID。作者继续使用各源已有的提取规则，EH/NH 不以 uploader 代替作者。
- 收藏操作失败在对话框内显示错误，界面根据数据库实际状态更新，不提示虚假成功。

主要文件：新增 `local_favorite_actions.dart`，接入四个 `*_comic_page_v2.dart`。不修改收藏数据库结构或下载逻辑。
