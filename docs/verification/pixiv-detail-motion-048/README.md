## Scope And Contracts

- The user confirmed that closing returns to the opening mode and position: gallery to gallery, inline to inline. It does not always remove inline content.
- Header progress is `clamp((H - h - (G - pixels)) / h, 0, 1)`. The avatar/title/author cluster keeps its compact measured width and moves left by `52 * progress` dp. The download action stays fixed.
- The arrow's fixed layout size is 52x48 dp. Its visible width is `52 * (1 - progress)` and its opacity is `1 - progress`. Visible widths below 48 dp have no arrow hit or descendant semantics; the cluster remains an explicit button.
- The panel opens in 260 ms with `easeOutCubic`, closes in 200 ms with `easeInCubic`, and supports reversing from the current visual value. Height remains 75% of the safe viewport. Scrim alpha is `.24 * value`.
- One details GlobalKey/State tree migrates between inline, panel, and parking. Closing retains the panel host until dismissal, then restores the source mode. No duplicate trees or AnimatedSwitcher.
- Main Controller and ScrollPosition identity are retained. Opening stops inertia and the full-screen barrier intercepts background input; physics is not replaced.
- Silent corrections use a separate paint/semantics notification, not scroll notifications. Header paint, hit testing, and coordinate transforms read the same final position. Counter/favorite State synchronization is safely queued after layout without activating the handoff.
- Reduced motion reaches the panel endpoint on the next pump; scroll-driven header geometry still follows its anchor.

## Implementation Lessons

- Calling a sibling's `markNeedsLayout` from Viewport layout triggers a Flutter mutation assertion. Merely reading pixels in an independent overlay's layout does not cover silent corrections. Fixed layout plus a shared live paint/hit/semantics transform solves both problems without a delayed header frame.
- `Center` in the download action expands under a finite maximum width. The custom row must measure this non-flex child with the same unconstrained natural-width policy as the original Row; otherwise it consumes the whole row and squeezes the cluster to 1 dp.
- Changing scroll physics at panel-open time causes Flutter to replace its Position. Use the barrier and `goIdle` instead.
- Legal offset clamping is not restoration evidence. Compare exact original pixels, mode, image/header rectangles, and State identity.
- Lazy comment slivers can refine their estimated max extent after first real layout. That does not authorize a pixel change or extra tail spacer; tests check strict pixels and actual geometry, plus only the original anchor and 88 dp tail adapters.
- Tooltip text may be a semantic `tooltip` field rather than the node label. Semantic tests must inspect the real fields and dispose their SemanticsHandle before test completion.
