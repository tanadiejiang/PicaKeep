## 本轮改动

1. `_IllustLayoutDelegate` 在同一实例内去重相同首尾索引。同帧多次 layout 最多发布最终范围一次；更换 delegate 首次范围重新通知。减少重复 ID/Set 分配、队列遍历，不改队列 idle/前后台/重试唤醒规则。
2. `cache_file_inventory.dart` 用工作 isolate 遍历、stat、去重和排序三个既有缓存根。原 `_directorySize` 有 128 个 inclusive 样本分布在约 379ms 区间，旧异步 IO 的调度与列表构造仍占用界面 isolate。
3. 清理继续在主 isolate 执行，保留既有合并与 30 秒节流。每次删除前复查根目录、当前配额、租约与文件 size/mtime/ctime，变化文件留给下一次维护；`.part` 算占用但不可删，重叠根不重复算。已消失或变小文件更新剩余量，避免多删其它缓存。
