## 009：推荐页瀑布流

探索recommend的分组概览和分页列表均使用SliverMasonryGrid，逐项懒构建。分组标题、错误/重试、查看更多、分页footer、滚动、隐藏页面保活和账号指纹沿用原流程。隐藏屏蔽项先过滤，避免瀑布流空洞；显示屏蔽项保留淡化和原因。榜单、分类结果保持原布局。

共享卡片新增可选作者头像与收藏插槽。作者头像20dp，使用原50px头像URL与防盗链头，缺失/失败用首个完整字符；Pixiv可靠authorId才提供作者路由。图片保留原比例，Pixiv比例缩略图失败回原图URL。全局瀑布流圆角4dp；作者页不重复增加头像/爱心。

右下角爱心34dp点击区、22dp图标，贴封面边缘且无底色/阴影；已收藏玫红#E0245E、未收藏白色，默认90%不透明度。设置保存在settings[150].waterfall，支持玫红/主题色、50–100%每10一档。推荐标签默认开启2行，可选1/2/3/不限；有限行数固定预算，不限自然高度。本地/作者旧配置默认关闭2行。设置确定才保存并合并最新其它节点；显示通知仅重建卡片，不重新请求推荐数据。

列数复用settings[156]，保留当前保存值。调研报告称默认2列，但当前代码实际默认3列，本轮没有强制重置用户设置。报告称旧标签档位2/3/不限，实际旧档位1/2/3；本轮扩展0为不限，保留旧值。

Pixiv列表解析authorId/profileImageUrl/bookmarkData/isBookmarkable，不逐卡请求详情。只有可靠Pixiv brief且isBookmarkable为true时显示平台收藏按钮，其它来源采用保守兜底。收藏复用006严格写通道；同feed同作品共享状态与忙锁，失败保留图标，刷新/账号变化丢弃过期结果。登录返回刷新数据，不自动写；点击爱心/作者不打开详情，详情返回刷新推荐数据读取最新收藏态。

使用用户现有游客JSON验证字段，登录态用离线fixture覆盖。游客JSON不能证明真实账号书签写接口；本轮未进行真实账号操作。视觉预览由tool/preview_recommend_waterfall_009_test.dart使用实际产品组件和本地附件封面生成，无在线图片请求。

## 010：章节断点恢复

旧流程有两处重复成本：启动遍历已完成章节文件；每次写章节记录递归统计整本文件大小。新增仅在完整落盘后提交的完成检查点、原下载路径/页数/章节字节数与下一问题章节游标；新格式普通续传信任持久化检查点，当前章仍复用并校验既有页。大小按逐章记录累计，避免每章扫描整本。

currentEp只决定旧任务的优先处理章节，不证明前面的章节已完成。旧队列先恢复停止/问题章，再做一次必要的历史完整性迁移；迁移进度持久化，随后可快速续传。无权威页数的旧记录需要源页表核验，不能仅凭已有非空文件证明不存在缺失尾页。

主动选章状态查询/新入队仍进行文件核验，发现缺文件会撤销对应检查点并交回下载器。普通续传信任边界是不自动发现用户在外部手工删除或改动已提交文件；需要打开章节状态面板主动检查。保留稀疏原始章节索引、每章DB/queue提交、追加存盘回滚与快速暂停恢复的取消代数。
