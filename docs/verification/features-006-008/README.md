## 实现与行为契约

### 006：Pixiv与卡片标签

- 作品详情从bookmarkData初始化当前账号收藏态，作者详情从isFollowed初始化关注态；游客缺失字段默认false。作品userId是作者UID，自关注门禁取当前登录账号UID。
- 取消收藏先读取最新bookmarkData.id再提交，不能把作品ID当书签ID。添加保留JSON接口，删除与关注/取消关注使用各自Web表单接口。Dio离线adapter验证实际body/header与明确成功结构，4xx、HTML、未知结构、网络失败不误判成功；网络错误不重放写操作，明确认证拒绝仅刷新令牌重试一次。
- 收藏点按与长按确认共享页面状态锁；作者关注、账号管理返回、刷新、换作者及销毁都有过期结果保护。失败保留图标，最新反馈替换旧SnackBar；登录回来重读资料，不自动提交关注。following是作者关注别人的数量，不能因“我关注作者”加减。
- settings[150].waterfall.local/pixivAuthor分别配置本地与作者卡片标签，默认关闭、2行，可选1/2/3行。共用显示组件按固定行预算保留高度，空标签也保留预算；设置确定才保存，保存合并最新普通卡片配置，普通卡片编辑器也保留瀑布流配置。
- 设置入口为浏览→插画列表→瀑布流卡片标签，作者页另有标签按钮。标签不写入settings[158]信息模板。

依据005调查与主代码复核；Web请求参考[Pixiv Previewer原始脚本](https://raw.githubusercontent.com/Ocrosoft/PixivPreviewer/6142d3217d41f198c219bc8a763387cf4ab272e1/pixiv%20previewer.user.js)。离线wire测试不能代替真实账号服务端验收。

### 007：标签规划

保留004可见行懒挂载与标准FilterChip。最多2048条共享LRU文字尺寸缓存按label、完整TextStyle、TextScaler、locale、direction和TextHeightBehavior区分；每组件最多保留2份行计划，数据/选中/几何/宽度变化正确失效。前12显示时仍可为候选标签预热，每批最多4个新测量且约800µs，8ms定时调度，动画/待渲染帧时延后80ms，无setState或强制帧，销毁取消、旧环境失效，回退布局停止预热。

机制测试覆盖140候选预热后切全部/改宽/滚动不重新测文字、共享缓存重开与容量淘汰、候选替换和销毁。立即展开全部仍可能冷测；行计划仍是同步线性规划。没有新的after真机采样，不能声称已消除11.460ms语义尖峰或52.518ms慢帧，也不能把旧新非同操作样本的47%差值当FPS提升。

此前分析见`../illust-tags-004-recheck/README.md`，可靠统计为validated_trace_summary.json；原始统计中2个不闭合语义事件已排除，不把7s跨帧洞当真实耗时。CPU追踪写入15.81%self占比不直接从耗时扣除。

### 008：章节选择

原项目只读参考路径：D:/Flutter_Projucts/PicaComic_初始/PicaComic/lib/components/select_download_eps.dart，以及原JM/Picacg详情下载入口。旧面板支持点选和已下载禁选，长按滑选由当前项目新增。当前三章节源为JM、Picacg、Komiic；选择/记录索引0-based，目录/阅读器序号index+1。

多章详情下载进入85%高度选章面板，部分已下载也直接补章，保留原显式删除入口。六状态分别表达可下载、已下载、已排队、下载中、已暂停、失败待重试，非可下载状态禁选；暂停/失败由下载任务页恢复。支持逐项点选、全选可下载、反选、清空，以及长按按初始选择快照增选/取消区间、回退恢复、边缘自动滚动；普通滑动保持滚动。面板错误读取明确重试，提交失败保留选择，提交防重复与忙态返回保护，取消零入队，读屏逐项选择。

三个enqueue接收chapterIndexes，null为兼容整本，显式空集/越界拒绝，串行保存并再次去重。任务记录所选/完成集合、路径、源页数和失败信息，重启保留选择并暂停，旧缺字段队列恢复全章。动态pending循环只取原始索引，活动追加等待入队存盘成功再执行，失败完整回滚选择、章节数和源模型。章节任务独立取消代数处理快速暂停恢复，旧执行体退出后再调度，避免旧取消异常覆盖新状态。

每章所有源页确认写盘且连续非空后，立即保存DB完成记录、源pageCounts及队列；部分失败不标整章，完整章立即保留，重试复用已下载页。复用原根/目录、同路径完成集合；状态可聚合多个旧根，执行不把不同路径集合伪写到同一目录，也不搬删其它根。新记录可核验缺失尾页，旧记录无权威源页数只能核验可见编号缺口及非空，不能证明未知尾页存在。章节源已有按序号的历史映射不做名称猜测；入队活动任务若源章节顺序改变明确拒绝，避免静默错章。

临时目录测试使用离线load/write注入，但执行真实三源章节筛选、文件验证、SQLite保存、队列持久化/恢复；包含只下第2/4章、同目录补章、不覆盖旧页、活动追加、并发去重、部分失败/retry、丢尾页/零字节、旧队列、读状态错误、存盘失败全回滚和快速暂停恢复。UI测试覆盖11项，包括真实Base部分已下载详情→选章→取消、长按滑选与靠边滚动、320dp1.8x长错误、读屏、忙态关闭和销毁。
